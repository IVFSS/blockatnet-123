# Visual QA: ctrl.xyz vs blockatnet

## Comparison Checklist

### Header
- [ ] Dark background (`#0a0a0f`)
- [ ] Sticky navigation (fixed at top)
- [ ] Logo on left side
- [ ] Navigation links in center
- [ ] Connect button on right
- [ ] Color mode toggle
- [ ] Border bottom (`#3f3f46`)

### Hero Section
- [ ] Full-width gradient background
- [ ] Centered headline text
- [ ] Purple accent color (`#a78bfa`)
- [ ] CTA button with gradient

### Card Grid
- [ ] Dark card backgrounds (`#18181b`)
- [ ] Rounded corners (`16px`)
- [ ] Border color (`#3f3f46`)
- [ ] Hover effect (border highlight)
- [ ] Shadow on hover

### Typography
- [ ] Inter font family
- [ ] Headings: 700 weight
- [ ] Body: 400 weight
- [ ] Primary text: `#f9fafb`
- [ ] Secondary text: `#6b7280`

### Buttons
- [ ] Primary: Purple background
- [ ] Hover: White background, dark text
- [ ] Border radius: `12px`
- [ ] Padding: `12px 24px`

### Forms
- [ ] Dark input backgrounds
- [ ] Border color: `#3f3f46`
- [ ] Focus state: Purple outline
- [ ] Placeholder color: `#6b7280`

### Footer
- [ ] Dark background
- [ ] Border top
- [ ] Muted text color
- [ ] Link hover effects

### Responsive
- [ ] Mobile (390px): Single column layout
- [ ] Tablet (768px): Two column layout
- [ ] Desktop (1440px): Full layout
